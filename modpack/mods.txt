# Vocana: Resonance — curated mod list (Minecraft 1.21.1, NeoForge 21.1.x)
#
# Resolved in CI by scripts/resolve.sh: each entry becomes `packwiz modrinth add https://modrinth.com/mod/<id>`,
# so a wrong slug fails loudly instead of falling back to a Modrinth search. Required dependencies of every entry are
# added automatically by packwiz; the "Libraries" section only names the ones worth seeing at a glance.
#
# Line format:   <id> [required] [side=client|server|both]   # comment
#   <id>         a Modrinth slug (or an 8-character Modrinth project id where the slug could not be confirmed),
#                or cf:<curseforge-slug> for an opt-in CurseForge-only extra (resolved only when the workflow input
#                include_curseforge is true; such a .mrpack is for private use, see README.md).
#   required     the job fails when this entry cannot be resolved (Vocana's own dependency and the seven
#                Vocana-Compat targets). Everything else may fail without failing the job; the summary lists it.
#   side=…       overrides the side Modrinth reports (client-only mods are kept off dedicated servers).
# "## " lines are section headers (used in the summary); other "#" text is a comment. Blank lines are ignored.
#
# Every Modrinth entry below was checked for a NeoForge 1.21.1 build on Modrinth on 2026-10-16 (search-engine
# snapshots of modrinth.com and its mirrors; this container cannot reach modrinth.com). README.md lists the
# excluded and unverified candidates and why.
